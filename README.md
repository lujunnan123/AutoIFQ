# AutoIFQ · 自动询价助手

基于 PyQt6 的自动询价工具。当前流程：**登录飞书 / 螃蟹账号 → 选择咨询商家 → 读取飞书多维表格并筛选确认 → 构建表格 → 按线程数展开工作线程执行螃蟹上号**（账号密码登录）。

## 已实现

- 上传账号 TXT 清单，格式：`手机号----密码`；只有手机号时使用默认密码。
- **飞书扫码登录**：点击右上角「飞书未登录」，在打开的浏览器中使用飞书 App 扫码；
  登录成功后保存会话，并自动进入指定租户 / 多维表格。
- **飞书多维表格筛选数据源**：开始运行时先读取《三角洲成品号--小新》，
  在筛选窗口按文本 / 数字 / 日期 / 是否 / 图片条件筛选，预览并勾选记录后，
  再生成 Excel 询价表；不再需要手动上传 Excel。
- **螃蟹账号登录**：右上角「螃蟹未登录」状态按钮；登录后进入
  首页 → 回收中心 → 三角洲行动，读取回收坑位商家并保存会话。
- **咨询商家多选**：运行参数中的「咨询商家」改为多选框，商家名称来自螃蟹官网；
  开始询价前必须登录螃蟹账号并至少勾选一个商家。
- **自动对话询价**：对每个飞书账号 × 已选商家进入聊天坑位，发送
  账号内容图片和随机询问话术（消息间随机间隔 2-8 秒），等待商家回复并识别报价，
  回填到新建表格。
- **子线程代理**：「运行参数」卡片右上角「代理设置」配置随机 IP 接口；
  飞书登录和螃蟹商家登录保持直连，子线程登录/聊天使用代理。
- 「手动询价」按钮：每次打开一个独立的手动询价窗口，上传截图并指定商户测试报价；
  窗口拥有自己的商户勾选、超时/间隔参数和后台线程，仅与主界面共用询问话术库；
  每个窗口从主界面 TXT 原子领取 1 个手机号并删除该行，同级窗口不会重复领取；
  窗口内串行发送给多家商户，再统一轮询回复，多个窗口可以并行运行。
- **协议密码登录**：密码使用页面同款 RSA 公钥加密后，通过 `twiceLogin` 接口提交。
- **Playwright 仅用于获取易盾 token**：打开登录页、填写账号密码、触发登录请求，
  截取请求中的 `ydToken` 后**中止浏览器自己的登录请求**；真正的登录由协议客户端发送。
- 如出现易盾滑块，需要在可见浏览器中人工完成；工具不破解验证码。
- 捕获协议登录响应；需要身份选择时自动通过 `sign2token` / `queryMerchantToken` 换取 token。
- 调用 `detailInfo` 读取用户信息，日志输出用户名 / 用户 ID。
- 支持线程数、暂停/继续、停止；网络与浏览器操作在后台线程执行。
- **询问话术本地持久化**：保存到 `data/phrases.json`，启动自动加载。
- **运行参数本地持久化**：保存到 `data/parameters.json`，启动自动恢复。
- **咨询商家缓存**：主界面的商家名称与勾选状态保存到 `data/merchants.json`；
  手动询价窗口使用自己的商户勾选，不写入该缓存。
- **手机号咨询历史**：手机号 × 商家咨询记录保存到 `data/consult_history.json`，
  避免同一手机号重复咨询同一商家。

> 平台密码登录接口强制校验易盾 token：不带 token 的纯协议请求会返回「易盾token为空」。
> 因此无法在完全不获取易盾 token 的情况下完成登录；本工具将浏览器限定为 token 获取环节。

> 报价识别基于商家回复的文本内容；商家只发送图片 / 报价卡片时，
> 需要人工确认。账号内容图片附件会临时下载到系统临时目录，询价结束后自动清理。

## 运行

推荐使用项目自带虚拟环境（Windows）：

```bash
venv\Scripts\python -m pip install -r requirements.txt
venv\Scripts\python main.py
```

也可以直接使用系统 Python，但请确保安装依赖和运行程序使用**同一个解释器**：

```bash
python -m pip install -r requirements.txt
python main.py
```

首次运行前，把 `config.example.json` 复制为 `config.json`。

> 如果启动时报 `No module named 'openpyxl'`、`No module named 'PyQt6'` 等错误，
> 说明当前 IDE/终端选择的 Python 没有安装依赖。请在该解释器执行
> `python -m pip install -r requirements.txt`，或在 VS Code 中选择
> `venv\Scripts\python.exe` 作为解释器。

### Playwright 浏览器

默认使用系统已安装的 **Microsoft Edge**（`browser_channel: "msedge"`）。
如果本机没有 Edge，可将 `browser_channel` 设为空字符串并安装 Chromium：

```bash
python -m pip install playwright
python -m playwright install chromium
```

`browser_headless` 当前配置为 `true`：螃蟹登录的易盾 token 获取为无头运行。
实测账号的易盾为无感知验证，未出现人工滑块；如果某些账号出现滑块，请改为 `false` 后重试。

飞书扫码登录始终使用可见浏览器（需要人工扫码）；
读取飞书表格时默认先尝试无头，失败后自动改用可见浏览器。两者都使用
`feishu.browser_channel`（默认 `msedge`）。

## 打包为 EXE

双击或在项目目录运行：

```bat
build_exe.bat
```

脚本会安装依赖、安装 PyInstaller、执行单文件打包，并复制 `config.json`、`config.example.json` 和 `data/` 到 `dist/`。

输出：

```text
dist/AutoIFQ.exe
dist/config.json          # 实际配置（包含短信后台凭证，请勿外发）
dist/config.example.json
dist/data/                # 询问话术、运行参数、飞书/螃蟹登录状态、商家缓存
```

> `dist/data/feishu_state.json` 和 `dist/data/pxb7_state.json` 包含登录会话信息。
> 分发 EXE 前请删除这些文件，让使用者自行登录。

- 打包结果已通过内置冒烟测试：

  ```bat
  dist\AutoIFQ.exe --smoke-test
  ```

  该测试会构建主窗口、加载 Excel 依赖并启动一次无头 Edge，验证 Playwright 驱动可用。
- Playwright 使用系统已安装的 **Microsoft Edge**（`browser_channel: "msedge"`）。目标电脑没有 Edge 时无法获取易盾 token；可改为 Chromium 并自行安装浏览器。
- 单文件 EXE 启动时会解压到临时目录，首次打开会比源码运行稍慢。
- EXE 与 `config.json`、`data/` 必须放在同一目录，运行后生成的表格在 `dist/output/`。
- `build/`、`dist/`、`*.spec` 已加入 `.gitignore`。

## 账号清单格式

```text
13800138000----自定义密码
13900139000
13700137000----AnotherPass!2026
```

- `手机号----密码`：使用指定密码。
- 只有手机号：使用 `config.json` 中 `login.default_password`（默认 `Aa123456`）。
- 同一号码重复出现时，显式密码优先于仅手机号。
- TXT 支持 UTF-8 / GBK 等常见编码。
- **注意**：手动询价窗口会在点击开始后领取手机号，并把该行从 TXT 中
  删除，其他同级手动窗口随后领取的是剩余号码；需要再次使用请重新上传
  完整清单。

## 任务流程

1. 启动程序，点击右上角「飞书未登录」，在浏览器中使用飞书 App 扫码登录。
   登录成功状态会保存；如果会话过期，重新点击右上角登录即可。
2. 点击右上角「螃蟹未登录」登录螃蟹账号；登录成功后自动获取
   三角洲行动回收坑位商家，并显示在「运行参数 → 咨询商家」多选框中。
3. 上传账号 TXT（不再需要上传 Excel）。
4. 点击「开始询价」后：
   - 必须已登录飞书、已登录螃蟹账号，并至少勾选一个咨询商家；
   - **先读取飞书多维表格并构建本地 Excel 询价表**（全局前置，不计入线程步骤）；
   - 构建成功后，按线程数展开工作线程；
   - 构建失败则停止，不执行任何账号登录。
5. 每个线程（账号）执行螃蟹密码登录：
   - 如启用子线程代理，先从代理接口获取一条随机代理；获取失败则跳过该账号；
   - Playwright（无头）通过该代理打开螃蟹密码登录页，填写账号密码并勾选协议；
   - 如出现滑块，将 `browser_headless` 设为 false 后人工完成；
   - 截取易盾 `ydToken` 并中止浏览器登录请求；
   - 协议客户端通过同一代理使用 RSA 加密密码并登录，读取用户信息；
   - 失败记录错误，继续后续账号。
6. 登录流程结束后进入**对话询价**：从 TXT 中成功登录的手机号池中，
   为每个「飞书账号 × 已选商家」分配一个尚未咨询过该商家的手机号，
   进入商家聊天坑位，发送账号内容图片和随机话术，等待商家回复（单次超时），
   识别报价并回填表格。同一手机号不会重复咨询同一商家；
   聊天浏览器继续使用该账号登录时分配的代理。

> 登录请求由 Python 协议客户端发出；浏览器只负责通过易盾验证。
> 若账号密码错误，接口返回「账号或密码错误」，不会消耗浏览器的登录状态。

## 飞书扫码登录

- 入口：界面右上角状态按钮（`飞书未登录` / `登录中…` / `飞书已登录`）。
- 点击后打开可见的 Microsoft Edge 窗口，使用飞书 App 扫描二维码；
  工具不会代替用户扫码，也不处理验证码。
- 扫码成功后工具会：
  1. 进入配置中的租户（`杭州维音信息科技公司`）；
  2. 打开 `Auto测试库` 中的 `三角洲成品号--小新` 表；
  3. 将登录状态保存到 `data/feishu_state.json`；
  4. 在运行日志中打印登录与目标表结果。
- 登录状态文件包含飞书会话 Cookie，**请勿外发**；`data/` 已加入 `.gitignore`。
- 登录等待时间由 `feishu.login_timeout` 控制（默认 300 秒），超时后需重试。

## 螃蟹账号登录 / 咨询商家

- 入口：界面右上角状态按钮（`螃蟹未登录` / `登录中…` / `螃蟹已登录`）。
- 账号来自 `config.json` 的 `pxb7_account.phone` / `password`；
  登录状态保存在 `data/pxb7_state.json`，下次优先复用。
- 启动时如果检测到已保存的螃蟹登录状态，会直接显示「螃蟹已登录」，
  并加载 `data/merchants.json` 中缓存的商家和勾选状态，不需要先点击登录；
  点击右上角状态按钮仍可刷新/验证商家列表。
- 与飞书状态按钮一样，启动时显示「已登录」只代表本地保存过会话；
  会话是否真正过期，以刷新商家或实际询价时的结果为准。
- 登录成功后访问首页 → 回收中心 → 三角洲行动，
  读取 `queryRecycleMerchant` 回收坑位接口，提取商户名称。
- 商家名称显示在「运行参数 → 咨询商家」的复选列表中：
  - 每次登录/刷新获取商家后，所有商家默认保持未勾选，需要手动选择；
  - 支持「全选 / 清空」；
  - 主界面的勾选状态与最近一次商家列表保存到 `data/merchants.json`；
    手动询价窗口的勾选不写入该文件，也不影响主界面。
- 点击开始询价前，必须至少勾选一个商家，否则不会执行任务。
- 如登录时出现滑块或验证，工具会改用可见浏览器并等待人工完成；
  可把 `pxb7_account.headless` 设为 `false`。

## 子线程代理设置

- 入口：「运行参数」卡片右上角「代理设置」按钮，以及按钮左侧的代理状态圆点。
- 代理状态圆点：
  - 红色：代理未开启；
  - 绿色：代理已开启；
  - 点击圆点可直接切换开关，并保存到 `data/proxy_settings.json`；
  - 默认不开启；如果本地已保存启用状态，启动时按保存值显示。
- 可配置：
  - 通过圆点或「代理设置」对话框启用/关闭子线程代理；
  - 代理接口地址；
  - 每次获取数量（接口请求时覆盖 URL 中的 `num`）；
  - 请求超时；
  - 「测试获取」按钮，成功后显示获取到的代理 IP。
- 执行时：
  - 飞书登录、飞书表格读取、右上角螃蟹商家登录始终直连，直到程序结束；
  - 飞书表格和商家数据准备完成后，主界面与手动询价的每个账号登录任务
    都从接口获取随机代理；
  - 同一账号的易盾验证浏览器、协议登录请求和聊天浏览器使用同一条代理；
  - 代理获取失败或代理登录失败时跳过该账号，不会回退直连；
  - 代理 IP 不会在不同账号之间重复分配，一批用完自动重新获取。
- 代理设置保存在 `data/proxy_settings.json`，包含代理接口密钥，请勿外发。
- 支持 `ip:port`、`http(s)://ip:port`、`socks5://ip:port` 及带用户名密码的格式；
  优先使用 HTTP/HTTPS 代理，SOCKS5 认证支持取决于环境。
- 代理接口请求本身直连。若接口返回“请先添加白名单”，需要把接口返回的公网 IP
  加入代理服务商白名单，再在「代理设置」中点击「测试获取」。
- 代理线路较慢时：
  - 登录页会等待最多 30 秒，必要时自动刷新一次；
  - 带代理的易盾 token 等待上限提高到 300 秒；
  - 登录页仍找不到「密码登录」时，会把失败截图保存到
    `output/proxy_login_failure_*.png`；
  - 单个账号的代理登录可能需要几分钟，请以日志为准；
  - 点击「咨询商家」后聊天弹窗最多等待 60 秒，聊天界面加载最多等待 90 秒；
  - 聊天界面仍加载失败时，会把截图保存到
    `output/proxy_chat_failure_*.png`，并记录页面 URL 和文本。

## 对话询价 / 报价回填

- 聊天账号来自 TXT 中登录成功的手机号；协议登录得到的 token 会注入
  官网会话，使用该手机号进入商家聊天。右上角螃蟹登录会话只用于获取商家列表。
- **一个手机号对同一家商家只执行一次咨询**：
  - 程序在分配任务时检查 `data/consult_history.json`；
  - 如果该手机号已经咨询过该商家，自动切换到下一个未咨询该商家的手机号；
  - 如果所有手机号都已咨询过该商家，则跳过此任务，表格报价列写「未报价」；
  - 需要重新咨询同一组合时，删除 `data/consult_history.json` 或换用新手机号。
- 所有商户统一执行“手机号 × 商家”去重，不再对特定商户开放重复咨询。
- 发送给商家的消息之间随机等待 2-8 秒：多张账号内容图片之间、
  最后一张账号内容图片与随机话术之间都会插入间隔。
- 对每个飞书账号记录、每个已勾选商家：
  1. 选择未咨询过该商家的手机号；
  2. 在回收坑位找到该商家，点击「咨询商家」进入聊天；
  3. 从飞书「账号内容图片」字段下载图片并发送；
  4. 从「询问话术」中随机选一句并发送；
  5. 等待商家回复，最长等待时间取运行参数「单次超时」；
  6. 从商家文本回复中识别价格（支持 `3200`、`3.2k`、`3千`、`3万`、
     `报价 3200`、`¥3200` 等格式）；
  7. 将商家名称和报价写入新建表格末尾的 `商家N名称` / `商家N报价` 列。
- 如果某条记录的「账号内容图片」为空，则跳过该行，不进入任何商家聊天；
  运行日志会以错误级别打印该条账号和「账号内容图片为空」原因。
- 任何单个任务的错误、会话失败或超时都会跳过并继续下一个任务，不会中断整体流程。
- 未在超时时间内识别到报价时，表格对应报价列写入「未报价」，日志记录
  商家的实际回复内容，便于人工跟进。
- 询价阶段按手机号分组顺序执行；商家较多时会耗时较长，可用
  「操作间隔」控制每次任务之间的间隔。
- 聊天进入、话术发送和商家回复接收流程已用昊天回收坑位验证；
  报价识别取决于商家是否以文本给出价格。当前表格前几条记录的
  「账号内容图片」字段为空时，这些行会被跳过并在日志中打印账号和错误。

## 手动询价

- 账号上传卡片右侧的「手动询价」按钮会打开独立窗口，标题为
  “手动询价 #1”“手动询价 #2”……；每次点击都会新建一个独立窗口。
- 窗口按当前屏幕可用高度自动调整：普通屏幕使用紧凑布局，
  屏幕较小时内容区出现纵向滚动，不会把窗口撑出屏幕。
- 功能：
  - 支持多张账号截图：点击选择、拖拽多个文件，或按 `Ctrl+V`
    粘贴剪贴板截图；列表显示缩略图，可移除选中/清空；
  - 支持 PNG / JPG / JPEG / WEBP / BMP，最多 20 张；
  - 「本次咨询商家」是本窗口自己的复选框列表：打开时不继承主界面的
    勾选结果，也不会写回主界面；主界面刷新商家名称时只更新可选列表，
    不覆盖本窗口的勾选；
  - 每个窗口的「单次超时」「操作间隔」完全独立，使用默认值或本窗口
    修改后的值，不读取主界面和其他手动窗口的当前值；
  - 询问话术仍只使用主界面的同一个话术库，不单独保存副本；
- **手机号领取规则**：
  - 点击开始后，本窗口的后台线程从主界面 TXT 中领取 1 个手机号；
  - 领取的同时从 TXT 文件中删除该手机号所在行，写入使用原子替换；
  - 同级手动窗口使用同一个 TXT 时会领取不同号码，不会重复；
  - 如果登录失败属于账号密码等非代理问题，会继续领取下一个，
    直到成功或清单为空；
  - 代理连接失败（如 `ERR_TUNNEL_CONNECTION_FAILED`、行为验证失败）
    会更换代理重试同一手机号，最多 3 次；
  - 连续 3 个代理仍失败时，会把该手机号放回 TXT 并停止本窗口登录，
    避免消耗账号；代理获取失败同样不会消耗 TXT 手机号；
  - 手机号成功登录后即从清单删除；需要重新使用时请重新上传完整 TXT；
- **同一窗口串行、同级窗口并行**：
  - 单个手动窗口内严格串行，不会同时操作多个商家或浏览器；
  - 多个手动窗口各自拥有后台线程，可以同时运行；
  - 同级窗口通过上面的原子领取机制使用不同手机号；
- **先发送、后监测回复**：
  1. 按顺序进入每家商户聊天，发送账号截图和随机话术，聊天窗口保持打开；
  2. 所有商户都发送完成后，再轮流检查各聊天窗口的新回复；
  3. 每家的「单次超时」从该商户发送完成时开始计算，不是串行等待
     完上一家再开始下一家；因此多家商户的总回复等待时间不会简单叠加；
  4. 发现可识别报价后立即记录；超过单家超时仍无报价则记「未报价」；
- 右侧「实时报价」卡片按商户显示：
  `待询价 / 发送中… / 已发送 · 等回复 / ¥报价 / 未报价 /
  已咨询过 / 失败 / 已取消`；
- 窗口内「询价日志」实时显示发送进度、商家回复和识别报价；
- 自动生成/追加一份询价日志 Excel，保存到 `output/手动询价日志_时间戳.xlsx`；
  每个商户一行。
- 日志表格列：时间、商户、手机号、截图文件、询问话术、商家回复、识别报价、状态、耗时、错误；
  多张截图的文件名以分号连接；手机号写入前会脱敏。
- 粘贴到临时目录的截图会在窗口关闭时自动清理；文件选择方式添加的截图不做复制。
- 登录手机号来自主界面导入的 TXT 账号清单；右上角「螃蟹登录」账号只用于
  获取/同步商户列表，不参与手动询价的聊天登录。
- 每个窗口领取的手机号从代理设置获取随机代理，易盾 token、协议登录和
  聊天浏览器使用同一条代理；代理获取或登录失败不会回退直连。
- 去重规则：同一手机号不会重复咨询同一商户；如果领取到的手机号已经
  咨询过某个选中商户，该商户标记为「已咨询过」并跳过（本窗口不会自动
  换另一个手机号）。咨询历史的读取和标记在进程内锁中完成。
- 使用前需要：
  1. 主界面已导入账号 TXT；
  2. 已通过右上角「螃蟹登录」获取咨询商家；
  3. 主界面至少配置了询问话术（没有话术时使用默认话术）。
- 每个手动窗口开始询价时都会创建自己的后台线程；窗口内任务串行执行，
  不同窗口可以并行。多个窗口并行时会按行领取不同手机号，请确认 TXT
  中的账号数量和代理数量足够。
- 先发送后监测会同时保留多家商户的聊天标签页；商家很多时浏览器内存
  占用会增加，建议分批询价或适当减少单窗口商户数。
  如需使用代理，请在主界面「代理设置」中启用。

### 能否完全去掉浏览器？

不能。密码登录接口强制校验易盾 token，纯协议不带 token 会返回「易盾token为空」。
当前的无头 Playwright 只用于取得该 token，实际登录请求已经完全协议化。
如果拥有其他合法的易盾 token 获取渠道，可以将其替换为纯协议 token 来源；
否则必须保留这个无头 token 获取步骤。

## 飞书数据源要求

目标多维表格中需要有这 6 个字段名（列顺序可以不同）：

```text
账号、账号内容、收购日期、可不可二次、成本、拉群前报价
```

- 工具会打开配置中的目标表链接，解析页面加载时返回的字段和记录接口，
  再按字段名映射这 6 列。
- 飞书新版多维表格的网格可能使用 canvas 渲染，无法通过复制网页内容取数；
  工具改为直接读取页面的字段 / 记录数据。
- 读取字段名时会忽略空格、换行和 `【】` / `[]`；缺少字段时日志会列出缺少项。
- 飞书表格只读，不会修改原表；只在本地生成新的询价表。
- 如果登录状态过期，构建会失败并提示重新点击右上角登录飞书。

## 读取飞书数据、筛选与构建表格

点击「开始询价」后的前置流程：

1. 使用已保存的飞书登录状态打开目标多维表格；
2. 读取当前视图已加载的上述 6 个字段记录；
   - 同时读取「账号内容图片」的附件元信息；
   - **此阶段不下载图片**；
3. 打开「筛选飞书数据」窗口：
   - 支持文本、数字、日期、是/否选项、「上架情况」和
     「是否有账号内容图片」条件；
   - 支持多条条件「满足全部（且）」或「满足任一（或）」；
   - 展示筛选结果、账号内容、成本、报价、上架情况和图片数量；
   - 默认只勾选有账号内容图片的记录，无图片记录仍显示但默认不选；
   - 支持逐条勾选、全选、取消全选、仅选有图片；
   - 用户点击「确认并开始询价」后还会再弹出一次汇总确认；
4. 只为最终确认选中的记录下载账号内容图片；
5. 使用确认后的记录新建本地 Excel 工作簿（工作表名「自动询价」），
   写入 6 列并追加已选商家的名称/报价列；
6. 默认保存到项目 `output/自动询价表格_时间戳.xlsx`，路径会写入日志；
7. 构建成功后才会展开线程；构建失败时线程不执行。

> 飞书页面首次返回的 `clientvars` 通常只包含前 200 条记录。
> 程序会再调用飞书记录分页接口补全当前视图的剩余记录；
> 只有补全失败时，筛选窗口才会提示“当前接口只加载了部分记录”。
> `excel.copy_limit` 不再截断筛选流程；实际询价条数由用户在筛选窗口勾选决定。

> 飞书网页版可能随版本调整页面结构。工具会先尝试无头浏览器读取；
> 若读取失败，会自动改用可见浏览器重试，并在日志中提示。
> 如仍失败，可尝试重新登录飞书后再运行。

## 线程进度展示

- 进度区顶部只有一行「构建表格」状态，不再占用线程步骤。
- 构建成功后，按【线程数】创建对应数量的工作线程；线程进度以**列表行**形式展示，不使用卡片。
- 每行显示：线程号 / 脱敏手机号 / 四个步骤的状态点 / 线程总进度。
- 登录阶段每个线程从账号队列取一条数据处理；该条数据完成或失败后，
  **该列表行立即移除**，线程继续取下一条数据。
- 登录阶段结束后进入对话询价，进度区按「飞书账号 × 商家」逐个添加任务行，
  完成、失败或超时后移除；询价任务按顺序执行。
- 登录阶段的活跃列表行数不超过线程数；全部任务完成后列表清空，
  日志和状态栏给出账号登录与报价任务汇总。
- 线程之间独立更新，互不覆盖。

## 排查

- **账号或密码错误**：检查 TXT 中密码是否正确；测试账号默认密码 `Aa123456` 不一定适用。
- **未获取到易盾 token**：若账号出现滑块，将 `browser_headless` 设为 `false` 后人工完成。
- **无需人工滑块**：实测账号的易盾为无感知验证，无头模式即可自动取得 token。
- **易盾token为空**：说明协议请求没有携带 token，检查 token 获取步骤。
- **浏览器没有弹出**：确认已安装 Playwright 与 Edge；或改用 Chromium 并安装浏览器。
- **`No module named 'openpyxl'`**：运行程序的 Python 未安装依赖；在该解释器执行 `python -m pip install -r requirements.txt`，或改用项目 venv。
- **飞书未登录 / 会话失效**：点击右上角「飞书未登录」重新扫码；成功后会重新保存登录状态。
- **飞书表缺少必要字段**：日志会列出缺少的字段名与当前字段列表，补全后重新运行。
- **飞书表格读取失败**：查看日志中的字段缺失或接口错误提示；可尝试重新点击右上角登录飞书后重试。
- **没有生成新表格**：检查飞书登录状态、目标表链接和必要字段；失败时查看日志中的表格错误。
- **螃蟹未登录 / 商家列表为空**：点击右上角「螃蟹未登录」重新登录；
  检查 `pxb7_account` 的账号密码和 `recovery_url`。
- **螃蟹登录出现滑块**：将 `pxb7_account.headless` 设为 `false`，
  在弹出的浏览器中手动完成验证。
- **未能获取三角洲行动商家**：确认账号可以访问回收中心；查看日志中的接口/页面错误。
- **账号内容图片为空**：该行询价会被跳过，日志会打印账号和原因；补上图片后重新运行，
  该手机号 × 商家不会因跳过而被写入咨询历史。
- **代理接口提示“请先添加白名单”**：把接口返回的公网 IP 加入代理服务商白名单，
  然后在「代理设置」中点击「测试获取」。
- **子线程全部跳过 / 代理获取失败**：检查代理设置是否启用、接口地址、获取数量和
  白名单；代理失败不会回退直连，这是为了避免暴露真实出口 IP。
- **`ERR_TUNNEL_CONNECTION_FAILED` / 代理隧道建立失败**：Chromium 无法通过代理
  建立 HTTPS 连接，常见原因是代理 IP 失效、未加白名单、鉴权失败或线路不可用。
  手动询价会自动更换代理重试同一手机号（最多 3 次）；全部失败时会把手机号
  放回 TXT 并停止，不消耗该账号。请检查代理白名单、有效期和接口线路。
- **代理登录找不到“密码登录”**：代理线路可能过慢或页面被拦截。程序会自动刷新一次并
  保存截图；请查看 `output/proxy_login_failure_*.png`，必要时更换代理线路。
- **代理登录很慢**：单个账号的易盾验证可能需要数分钟；日志会显示代理地址和等待状态。
- **聊天界面加载超时**：程序会等待最多 90 秒，并保存
  `output/proxy_chat_failure_*.png`；请检查代理是否阻断 WebSocket，或更换代理线路。
- **行为验证失败**：部分代理 IP 会被易盾判定为风险，协议登录会返回“行为验证失败”；
  换一条代理 IP 重试即可。
- **点击开始没有反应**：确认已导入账号 TXT、飞书已登录、螃蟹已登录且至少勾选了一个咨询商家。
- 旧版短信链路诊断：
  ```bash
  python tools/sms_diagnose.py 13800138000
  ```

## 安全说明

- 账号密码来自本地上传的 TXT；日志不会输出密码或易盾 token。
- 飞书二维码由用户本人在官方页面扫码完成；工具不保存飞书账号密码，也不处理验证码。
- 飞书登录状态保存在 `data/feishu_state.json`，包含会话 Cookie，属于敏感信息，请勿外发。
- 螃蟹登录状态保存在 `data/pxb7_state.json`，同样包含会话 Cookie；
  螃蟹账号密码保存在 gitignored 的 `config.json` 中，不写入源码或日志。
- 飞书账号内容图片会在询价时临时下载到系统临时目录，询价结束自动删除；
  商家聊天内容会写入本地运行日志，请妥善保管日志和结果表格。
- `data/consult_history.json` 保存手机号与商家的咨询历史（含手机号），
  属于本地敏感数据，不会上传；删除该文件可重置咨询历史。
- `data/proxy_settings.json` 保存代理接口地址和密钥，属于敏感信息；
  代理账号密码不会写入日志，请勿把该文件外发。
- 手动询价的截图和询价日志表格保存在本地 `output/`，可能包含账号信息与
  商家回复，请妥善保管。
- Playwright 使用普通本地浏览器打开官方页面；工具不包含滑块破解、验证码识别或反检测逻辑，
  出现滑块时需要人工完成。
- 密码加密使用页面公开的 RSA 公钥，不包含任何私钥。
- `config.json`、`data/` 已加入 `.gitignore`，不会被提交；日志中的手机号做脱敏处理。
